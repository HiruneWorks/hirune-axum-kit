## Major Changes

- Select explicit GNU targets and ARM64 compilers on the native builder CPU.
  Compile only the application and migration production executables.
- Transfer and verify exact image configuration/filesystem hashes on physical
  ARM64. Compare portable OCI content instead of engine-local image IDs.
- Native checks apply migrations, run API/worker/maintenance, and verify role
  grants, encrypted backups, scheduling and physical PostgreSQL recovery.
- Use TCP PostgreSQL readiness to exclude the temporary Unix-only init server.
- Select the actual k3s node image platform when exporting and importing test
  images. Use the complete OS/architecture value at both boundaries. Other
  platform entries in Docker indexes can lack local filesystem layers.
- Publish accepted AMD64/ARM64 images as one verified index. Application tags
  remain `v<workspace-version>` and PostgreSQL tags remain `postgres-v<version>`.
  Branch, PR and manual verification runs do not publish template images.
- Deduplicate complete branch/PR CI runs without canceling tag publications.
